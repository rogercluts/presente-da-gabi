# Nosso 1 Ano ❤

Site de aniversário de namoro.

## Como editar
- **Textos, nomes, data, momentos, carta, motivos:** edite `config.js`.
- **Fotos:** coloque na pasta `fotos/` (ex.: `foto1.jpg`) e ajuste a lista `fotos` em `config.js`.
- **Música:** coloque um `.mp3` em `musica/nossa-musica.mp3` (ou mude o nome em `config.js`).

## Como ver
Abra `index.html` no navegador, ou publique pelo GitHub Pages
(Settings → Pages → Branch).
